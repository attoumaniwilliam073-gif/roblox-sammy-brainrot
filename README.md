## 🚀 Installation

1. Ouvre **Roblox Studio**
2. Crée un nouveau jeu
3. Copie les scripts depuis le dossier `scripts/`
4. Arrange les modèles depuis le dossier `models/`
5. Teste dans le jeu !

## 👨‍💼 Admin Commands

- `/tp [player]` - Téléporte un joueur
- `/kill [player]` - Tue un joueur
- `/give [item]` - Donne un objet
- `/god` - Mode dieu
- `/chaos` - Mode chaos total 🌪️
